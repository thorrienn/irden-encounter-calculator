О калькуляторе

Формулы:

  • ОЗ = 20 + END ( + индивидуальный бонус).
  • Точность: для ближнего боя — STR (или PER, если фехтовальное), для дальнего — PER, для магии — MAG. Добавляется бонус точности.
  • База урона: ближний бой — (STR+END)/4 (округление вниз); дальний — (PER+REF)/4; магия — (MAG+WIL)/4.
  • Модификатор оружия: берётся из таблицы (ближнее: 4/6/8, дальнее: 3/5/0, магия: 3/5/7). Для механического дальнего оружия используется фиксированный урон (8/12/28) вместо атрибутивной базы.
  • Парное оружие: если персонаж владеет парным боем (лёгкое оружие или наличие навыка), добавляется вторая атака с половинным уроном (округление вниз).
  • Защита:
    • Парирование = END + бонус щита + штраф брони (доступно при ближнем оружии или щите).
    • Уклонение = REF + штраф брони (доступно, если броня не тяжёлая и щит не большой).
    • Блокирование = END + бонус блокирования щита + штраф брони (только для среднего/большого щита).
    Итоговая защита: для ближнего боя — максимум парирования и уклонения; для дальнего — максимум уклонения и блокирования (если доступно); для магии — WIL.
  • Вероятность попадания: точный перебор бросков d20 с учётом критических успехов/провалов (20 — всегда успех, 1 — всегда провал, равенство перебрасывается).
  • Ожидаемый урон по цели: (урон атакующего - броня цели, минимум 1) × вероятность попадания.

Категория боя оценивается по коэффициенту R – то есть, по тому, насколько быстрее враги способны убить игроков, чем игроки врагов (по среднему урону за ход).

  • Легкий бой: R < 0.67 (игроки быстрее минимум в 1.5 раза).
  • Равный бой: 0.67 ≤ R < 1.5 (шансы примерно равны).
  • Трудный бой: 1.5 ≤ R < 2.0 (враги быстрее в 1.5–2 раза).
  • Смертельный бой: R ≥ 2.0 (враги минимум вдвое быстрее).

Примечание: расчёт использует приближённые оценки (сумма максимального и минимального урона по доступным целям) и предназначен для быстрой оценки.
